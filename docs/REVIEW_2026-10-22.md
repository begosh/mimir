## Verification

The original baseline had 41 passing tests. The final suite includes focused
regressions for the behaviors above and full mocked three-phase orchestration.
The recorded final test count is in `tasks/history.md`; one POSIX-only test is
skipped on Windows. Python compilation, `git diff --check`, and the skill-creator
validator pass (the latter requires `python -X utf8` on this Windows runtime).

with mocked git/Python, verifying fetch-branch entry and exit-code propagation.
Real SKF slide rendering and other provider/account paths were not exercised.

Live failures were retained as evidence: missing inherited Azure key, short
worker deadlines, JSON-example extraction and invalid reflection structure.
All three phases eventually completed successfully; the recovered worker's

Installed-package refresh preserves existing learned notes and backs up the old
copy. Final runtime/documentation byte comparison is recorded in the inventory.
No CLI provider settings were changed and no external messages were sent.

## Remaining limitations

- Default decomposition is flat; required-role coverage depends on the model's
  plan and required-evidence metadata. Depth fields do not implement recursion.
- JEV/confidence are model estimates. The default pipeline makes one reflective
  revision; meaningful dataset-scored Pareto optimization is a separate API.
- Codex read-only sandboxing controls filesystem writes. Remote MCP operations
  retain native permissions; query-only instructions are not an enforced remote
  allowlist. Permissions must be appropriate for configured tools.
- Blocking urllib work cannot be forcibly cancelled after its executor thread
  starts. Socket/deadline handling reports failure, but a thread can finish later.
  Windows cleanup reports unverifiable descendant termination; Job Object
  isolation is not implemented. The POSIX helper test was skipped here.
- Partial-task execution resume is intentionally unsupported. Failed execution
  leaves the planned checkpoint; retry reruns tasks. Use unique artifact names.
- Report files are individually atomic; report/sidecar/state/learning do not
  form one transaction. Concurrent runs targeting the same report, simultaneous
  memory appends and installation refresh require a wider consistency design.
- Complete evidence now survives transmission, but context has no measured token
  budget. Large fan-in can exceed a provider's limits. Public-query validation
  cannot recognize every confidential identifier; use --skip-web for private work.
- Generic OpenAI-compatible endpoint configuration intentionally sends the
  caller's configured key to the configured endpoint; endpoint trust remains a
  configuration responsibility. Other live providers were not certified.
- Source snippets/preprint abstracts are discovery evidence; full primary-source
  retrieval and dates still need assessment. Historical UX strategy documents
  contain past recommendations and are not a current implementation contract.

These are explicit boundaries and design opportunities, rather than claims that
the tests prove every failure mode absent.
