# Engine Evidence Capture & Downstream Span Completeness Qualification (P1.2) — 2026-10-26

## 1. Executive Summary

This qualification document closes **P1.2** from the Mímir backlog:
> *"Generate source identity and capture metadata in the engine; freeze retrieve-worker evidence and bind exact needed spans to dependents.
> Explicit retrieve-task capture implemented: engine reread, generated ID/time, frozen exact excerpts, durable dependent lineage and publication/recovery checks.
> Ordinary mixed research/tool-output capture and downstream span completeness remain pending."*

Previously, dynamic source capture was restricted to explicit `retrieve` operations (`operation == "retrieve"`). Ordinary mixed research workers (e.g. `operation == "research"` or tool-using workers) citing workspace files or external documentation were not automatically reread by the engine, creating admission gaps where unverified citations could bypass the Result Gate or propagate un-frozen citations. Furthermore, downstream tasks lacked an explicit span completeness gate to verify that all upstream claimed facts were backed by frozen spans before dependent execution.

This increment completes both requirements:
1. **Engine-Owned Capture for Mixed Research Workers**: Engine rereads workspace files and approved HTTPS URLs cited by any worker (`operation in ("retrieve", "research", "extract")` or `required_evidence`), computes content SHA256 hashes, assigns canonical `capture_<sha256>` IDs, extracts exact character-offset spans, verifies non-ambiguity, rebinds claim links, and caches captures across concurrent workers via `SourceStore._RUN_CAPTURES` to prevent timestamp version conflicts.
2. **Downstream Span Completeness Gate (`validate_downstream_span_completeness`)**: Enforces that every claim asserted as `supported` by an upstream dependency has an active, valid frozen span in `frozen_evidence`, and verifies that all explicit contract inputs (`contract["inputs"]`) are bound before dependent release.

The implementation is verified in [`tests/test_dynamic_source_capture.py`](../tests/test_dynamic_source_capture.py) (6/6 passing) and confirmed across the entire 37-test Priority 1 suite and 71-test Priority 2/3 regression suite.

## 2. Technical Architecture & Invariants

### 2.1 Unified Engine Evidence Capture Flow

```
[Worker Result with Citations]
               │
               ▼
┌──────────────────────────────────────────────┐
│  Check: Is citation unbound & capturable?    │
│  (Existing workspace file or allowed HTTPS)  │
└──────────────────────┬───────────────────────┘
                       │ Yes
                       ▼
┌──────────────────────────────────────────────┐
│  Engine-Owned Reread (capture_async)         │
│  - Reads raw bytes from workspace / HTTPS    │
│  - Reuses SourceStore._RUN_CAPTURES cache    │
│  - Computes SHA256 & canonical ID            │
│  - Verifies exact substring match for excerpt│
│  - Computes exact [span_start, span_end]     │
│  - Derives line_start / line_end             │
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│  Packet Assembly & Claim Rebinding           │
│  - packet["sources"] & packet["spans"]       │
│  - Worker ID -> capture_<sha256> (aliases)   │
│  - Claims rebound to engine capture ID       │
│  - Frozen packet inlined into supplied_sources
└──────────────────────┬───────────────────────┘
                       │
                       ▼
┌──────────────────────────────────────────────┐
│  Result Gate & Dependency Propagation        │
│  - Check bound citations deterministically  │
│  - Packet committed to envelope              │
│  - Inherited as frozen_evidence by dependents│
└──────────────────────────────────────────────┘
```

### 2.2 Invariants Enforced

1. **Worker Excerpts Never Create Captures**: An excerpt reported by a worker cannot establish its own authority. The engine performs an independent reread of the referenced file or URL.
2. **Deterministic Engine ID & Timestamp Integrity**: Capture IDs strictly follow `"capture_" + sha256({"locator": locator, "sha256": content_sha256})`. Timestamps are generated by the engine in UTC. To prevent microsecond skew across concurrent peer workers referencing the same file, `SourceStore._RUN_CAPTURES` guarantees identical capture records.
3. **Exact & Bounded Spans**: Supporting excerpts must be nonempty, bounded to 16,000 characters, and match uniquely in the source. If an excerpt is absent or appears multiple times ambiguously, capture fails closed (`"Engine source capture failed"`), rejecting the result and preventing dependent release.
4. **Downstream Span Completeness**:
   - `validate_downstream_span_completeness(node, dependency_results)` verifies that every source ID cited by upstream dependency claims has a valid span in `frozen_evidence`.
   - If an upstream task asserted a supported claim without corresponding frozen spans, downstream execution halts immediately (`ValueError: Dependent task '...' has incomplete upstream evidence: source '...' cited by dependency '...' is missing frozen spans`).
   - If a dependent contract requires explicit file or evidence inputs, all required inputs must be bound in available sources or locators prior to execution.
5. **Security & Workspace Boundaries**: Local files outside the workspace root or HTTPS URLs outside explicit `allowed_domains` fail closed without network calls.

## 4. Acceptance Criteria Verification

- [x] **Required rejected findings never release dependents or become unqualified published claims**:
  Verified by `test_mixed_worker_ungrounded_excerpt_fails_capture_and_blocks_dependent` where capture failure prevents dependent execution.
- [x] **Unknown/changed source versions and unsupported additions fail the relevant gate**:
  Enforced by `check_bound_citations` and `validate_downstream_span_completeness`.
- [x] **Engine identity and capture metadata**:
  Canonical `capture_<sha256>` IDs and engine UTC timestamps generated and cached deterministically.
- [x] **Freeze retrieve-worker and mixed research evidence**:
  Captured evidence packets are frozen in `envelope["captured_evidence"]` and propagated to `envelope["frozen_evidence"]`.
- [x] **Downstream span completeness**:
  Verified by `validate_downstream_span_completeness` before any dependent executes.
