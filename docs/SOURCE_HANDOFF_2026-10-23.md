# Captured-source handoff

See the [execution conclusions](EXECUTION_CONCLUSIONS_2026-10-23.md) for the
implemented contracts, current direct/API routing, measurements and limits.

Explicit manifests freeze source text, ID, locator, retrieval metadata, hash and status. Sources up to 16,000 characters may be supplied during planning and bound by exact named IDs during execution. Local paths are replaced by aliases in model-facing views. Dynamic retrieved-page binding and selective line slicing remain incomplete.
