# Task interpretation before retrieval

The original release (`f8dc13a`) ran `conduct_deep_scout(goal)` before
`decompose_goal`, with web enabled by default. That submitted the raw objective
through heuristic search templates before interpreting its components.

Normal planning now makes no preliminary search. The host can supply a bounded
task brief with the requested outcome, explicit constraints, components,
evidence needs and missing information. It is persisted, passed into task prompts
and frozen on resume. The original goal remains intact, including long questions.
Query/domain arguments are optional retrieval hints, not automatic network calls.

Single/review add no model planning call. If the host omits the brief, workers are
instructed to interpret before using tools and the checkpoint records
`worker_pending`. That instruction alone is not proof of semantic understanding
or enforced native tool order. Swarm's existing planning call returns a bounded
brief plus tasks. Codex planning uses its text-only runtime; other adapters receive
the same no-retrieval instruction without that runtime guarantee.

Regression checks cover absent pre-search, long-goal preservation, required swarm
briefs, focused-query hints, source qualification, task caps and frozen recovery.
Full suite: 263 passed, 9 skipped and 112 subtests passed.

Live Codex pizza planning attempts failed with a stream-disconnected-before-
completion error after approximately 25 seconds. A minimal text-only structured
call succeeded. The failure is unresolved; do not present the new swarm planning
output as live verified or claim that the provider itself is unavailable.

This change supports the intended self-hardening sequence: interpret, decompose,
retrieve evidence for unresolved components, challenge claims and revise with
explicit remaining gaps. The current normal planner creates a bounded flat task
graph and the normal review performs one critique/synthesis cycle; this change
does not establish recursive adaptive hardening or elimination of hallucinations.
